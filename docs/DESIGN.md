# 디자인 시스템

pango-groupware의 화면 기준입니다. 웹·iOS·Android가 같은 코드로 그려지므로 이 문서 하나로 세 플랫폼을 맞춥니다.
토큰 값은 `crates/web/assets/style.css`의 `:root`가 기준이고, 이 문서는 **왜 그렇게 정했는지**를 남깁니다.

## 1. 무엇을 위한 화면인가

- **사용자**: 수십~수백 명 규모 회사의 구성원과 관리자(인사·총무). 매일 아침·저녁에 열고, 결재와 휴가는 하루 몇 번 들릅니다.
- **해야 할 일**: 출퇴근, 결재 처리, 휴가 신청을 **몇 초 안에** 끝내는 것. 관리자는 예외(지각·누락·대기 문서)를 **한눈에** 찾는 것.
- **인상**: 회사 시스템답게 차분하고 정확해야 합니다. 화려함보다 신뢰, 장식보다 정보 밀도.

## 2. 원칙

1. **밀도 있게, 그러나 숨 쉬게.** 4px 격자. 데스크톱 컨트롤 높이 36px(밀집 32px), 모바일 터치 44px.
2. **선으로 나누고 그림자로 띄운다.** 패널은 1px 테두리만 쓰고 그림자를 주지 않습니다. 그림자는 화면 위에 뜨는 것(모달, 팝오버, 토스트, 바텀시트)에만 씁니다.
3. **모서리에도 위계가 있다.** 컨트롤 6px · 패널 10px · 모달 14px. 알약 모양은 상태 배지에만.
4. **영역마다 주 동작은 하나.** 주 버튼(채움) 하나, 나머지는 테두리 버튼. 되돌리기 어려운 동작은 빨간 글자 버튼 + 확인 단계.
5. **상태는 글자로 말한다.** 색 점 + 문구. 색만으로 상태를 구분하지 않습니다.
6. **숫자는 표처럼.** 고정폭 숫자(`tabular-nums`), 표에서는 오른쪽 정렬, 단위는 작고 흐리게.
7. **기다림과 비어 있음도 화면이다.** 불러오는 중에는 최종 모양의 골격(skeleton)을, 비어 있으면 이유와 다음 행동을 보여 줍니다.
8. **문구는 동사로.** 버튼은 결과를 말합니다("휴가 신청", "승인", "반려"). 같은 동작은 흐름 내내 같은 이름. 느낌표·사과 문구를 쓰지 않습니다.

## 3. 색

차가운 무채색 위에 브랜드 색 하나. 상태색은 채도를 낮춰 표 안에서도 시끄럽지 않게 합니다.

| 토큰 | 라이트 | 다크 | 쓰임 |
| --- | --- | --- | --- |
| `--ink` | `#18202B` | `#E9EDF3` | 본문, 제목 |
| `--graphite` | `#4A5565` | `#B3BCC8` | 보조 글자, 라벨 |
| `--fog` | `#8A94A3` | `#7D8796` | 메타 정보, 자리 표시 |
| `--hairline` | `#E3E7ED` | `#2A313C` | 테두리, 구분선 |
| `--canvas` | `#F5F7FA` | `#0F1319` | 앱 배경 |
| `--surface` | `#FFFFFF` | `#171C24` | 패널, 표 |
| `--brand` | `#3346D3` | `#7D8CF5` | 주 동작, 선택, 링크 |
| `--brand-tint` | `#EEF0FD` | `#1E2447` | 선택된 행·메뉴 배경 |
| `--positive` | `#12805C` | `#3CC495` | 정상, 승인 |
| `--caution` | `#B5670B` | `#E8A33D` | 지각, 대기, 곧 소멸 |
| `--critical` | `#CC2E3B` | `#F06B73` | 결근, 반려, 삭제 |

브랜드 색은 남색 계열의 `#3346D3`입니다. 흔한 밝은 파랑보다 무게감이 있어 "회사 시스템"의 신뢰감을 주고, 상태색(초록·주황·빨강)과 섞여도 구분됩니다.

## 4. 글자

- **서체**: Pretendard(OFL). 한글·영문·숫자의 폭과 굵기가 고르고, 고정폭 숫자를 지원합니다. 서체 파일은 앱에 포함하며(외부 CDN 금지 — CSP), 없으면 Apple SD Gothic Neo → Malgun Gothic → 시스템 산세리프.
- **크기**(데스크톱 / 모바일)

| 역할 | 크기 | 굵기 | 행간 |
| --- | --- | --- | --- |
| 화면 제목 | 22 / 22 | 700 | 1.3 |
| 섹션 제목 | 16 / 17 | 600 | 1.35 |
| 본문 | 14 / 15 | 400 | 1.55 |
| 강조 본문 | 14 / 15 | 600 | 1.5 |
| 메타 | 13 / 13 | 400 | 1.45 |
| 캡션 | 12 / 12 | 500 | 1.4 |
| 큰 숫자 | 28 / 28 | 700 | 1.1 |

- 17px 이상은 자간 `-0.01em`. 영문 대문자 라벨, 넓은 자간 라벨은 쓰지 않습니다.
- 메타 정보(부서, 직책, 시각)는 가운데 점으로 이어 붙이지 않고, 간격을 둔 별도 요소로 나열합니다.

## 5. 배치

### 데스크톱 (≥ 960px)

```
┌──────────┬───────────────────────────────────────────────────────┐
│ 회사 로고 │ 화면 제목                         [알림] [내 프로필]   │ ← 상단 바 56px
│          ├───────────────────────────────────────────────────────┤
│ 메뉴      │ 탭 / 필터 ...                          [주 동작]       │ ← 도구 줄
│ (240px)  │                                                       │
│          │ 본문 (최대 1280px, 좌우 여백 32px)                      │
│ ──────── │                                                       │
│ 팀       │                                                       │
│ 관리      │                                                       │
└──────────┴───────────────────────────────────────────────────────┘
```

- **구성원 화면**은 패널 조합(홈, 근태, 휴가).
- **관리자 화면**은 표가 중심입니다. 도구 줄 왼쪽에 필터, 오른쪽에 주 동작. 표 머리는 스크롤해도 고정, 행 높이 44px, 행 전체가 눌리는 영역.
- 좌측 정렬이 기본. 가운데 정렬은 빈 상태와 로그인 화면에만.

### 모바일 (< 960px)

- 상단 앱 바(제목) + 하단 탭 5개. 사이드 메뉴는 "더보기"로.
- 목록은 패널이 아닌 **행**(구분선, 오른쪽 꺾쇠). 표는 행마다 카드처럼 쌓습니다.
- 모달은 아래에서 올라오는 시트. 주 동작 버튼은 화면 폭 가득.

## 6. 대표 요소: 하루 막대

이 제품을 기억하게 하는 요소는 **하루 막대**(근무 타임라인)입니다. 장식은 이것 하나에만 씁니다.

```
 06    09 ▼출근 09:12             현재 ▼          18    22
 ├─────┼██████████████████████████░░░░░░░░░░░░░░┼─────┤
       └──── 근무 시간대(09:00–18:00) 옅은 띠 ─────┘
 이번 주 27시간 40분 / 40시간  ███████████████░░░░░░░░
```

- 근무 시간대를 옅은 띠로 깔고, 출근~퇴근(또는 현재)을 브랜드 색 막대로 칠합니다. 지각 구간은 주의 색.
- 아래에 이번 주 누적 근무시간 막대(40시간 기준, 52시간 상한 표시).
- 홈의 오늘 카드, 근태 화면 상단에 크게. 팀 현황의 각 행에는 높이 6px의 작은 막대로 반복합니다.

## 7. 구성 요소

| 요소 | 규칙 |
| --- | --- |
| 버튼 | 높이 36(데스크톱)/44(모바일). 주(채움) · 보조(테두리) · 조용한(글자) · 위험(빨간 글자). 아이콘만 있는 버튼은 `aria-label` 필수 |
| 입력 | 높이 36/44, 글자 16px(iOS 확대 방지). 라벨은 위, 오류는 아래에 빨간 글자 |
| 배지 | 상태 점 + 문구. 배경은 아주 옅게 |
| 표 | 머리 고정, 숫자 오른쪽 정렬, 행 hover 시 `--canvas` 배경 |
| 패널 | `--surface` + 1px `--hairline`, 10px 모서리, 안쪽 여백 20(데스크톱)/16(모바일) |
| 탭 | 글자 + 아래 2px 막대. 개수는 작은 숫자 배지 |
| 아바타 | 이름 첫 글자, 배경색은 구성원 ID로 정한 6색 중 하나(사람마다 고정) |
| 빈 상태 | 아이콘 + 한 줄 설명 + (있으면) 다음 행동 버튼 |
| 로딩 | 최종 모양의 골격. 회전 표시는 버튼 안에서만 |

## 8. 움직임

- 사용자의 동작에 답하는 움직임만: 모달·시트 열고 닫기(160ms), 펼침(120ms), 토스트(200ms).
- 페이지 진입 애니메이션, 카드마다 나타나는 효과는 쓰지 않습니다.
- `prefers-reduced-motion`이면 모두 끕니다.
