# 디자인 시스템

pango-groupware의 화면 기준입니다. 웹·iOS·Android가 같은 코드로 그려지므로 이 문서 하나로 세 플랫폼을 맞춥니다.
토큰 값은 `crates/web/assets/style.css`의 `:root`가 기준이고, 이 문서는 **왜 그렇게 정했는지**를 남깁니다.

## 1. 무엇을 위한 화면인가

- **사용자**: 수십~수백 명 규모 회사의 구성원과 관리자(인사·총무). 매일 아침·저녁에 열고, 결재와 휴가는 하루 몇 번 들릅니다.
- **해야 할 일**: 출퇴근, 결재 처리, 휴가 신청을 **몇 초 안에** 끝내는 것. 관리자는 예외(지각·누락·대기 문서)를 **한눈에** 찾는 것.
- **인상**: 회사 시스템답게 차분하고 정확해야 합니다. 화려함보다 신뢰, 장식보다 정보 밀도.

## 2. 방향: 결제 관리자 화면의 정돈됨

참고 방향은 **토스페이먼츠 관리자 화면**입니다(로고·이름·전용 서체는 쓰지 않고 시각 언어만 따릅니다).
돈을 다루는 화면답게 숫자와 상태가 또렷하고, 장식 없이 여백과 글자 굵기만으로 위계를 만듭니다.

1. **여백이 위계를 만든다.** 테두리 대신 여백과 회색 배경 단계로 영역을 나눕니다. 선은 표의 행 구분과 입력 포커스에만.
2. **제목은 크고 굵게, 본문은 편하게.** 화면 제목 26px/700, 본문 15px, 행간 1.6.
3. **입력은 회색으로 채운다.** 테두리 없는 `--grey-100` 바탕, 포커스 때만 브랜드 색 2px 테두리.
4. **버튼은 세 단계.** 주(채움) · 옅은(브랜드 옅은 바탕 + 브랜드 글자) · 회색(회색 바탕 + 진회색 글자). 위험 동작은 빨간 옅은 버튼 + 확인 단계. 영역마다 주 버튼은 하나.
5. **상태는 옅은 알약 배지.** 옅은 바탕 + 진한 글자. 색만으로 구분하지 않고 항상 문구를 씁니다.
6. **숫자는 표처럼.** 고정폭 숫자, 표에서는 오른쪽 정렬, 단위는 작고 흐리게. 핵심 숫자는 크게(28px/700).
7. **기다림과 비어 있음도 화면이다.** 골격(skeleton)으로 기다리고, 비어 있으면 이유와 다음 행동을 보여 줍니다.
8. **문구는 동사로, 존댓말 해요체.** 버튼은 결과를 말합니다("휴가 신청하기"가 아니라 "휴가 신청"). 안내 문장은 "~해요/~했어요".

## 3. 색

회색 10단계 위에 파랑 하나. 상태색은 옅은 바탕 + 진한 글자 짝으로만 씁니다.
글자는 바탕과 4.5:1 이상이어야 하므로 **글자에는 `--grey-600` 이상만** 쓰고(`--grey-500` 이하는 아이콘·선·비활성),
옅은 바탕 위의 색 글자는 한 단계 진한 `-strong`을 씁니다.

| 토큰 | 라이트 | 다크 | 쓰임 |
| --- | --- | --- | --- |
| `--canvas` | `#F9FAFB` (모바일 `#F2F4F6`) | `#101014` | 앱 배경. 모바일은 패널 사이 띠가 또렷하도록 한 단계 진하게 |

패널은 `--canvas` 위에 놓여 테두리 없이 구분됩니다. 다크 모드에서도 같은 단계 관계(배경 → 패널 → 회색 50 → 100)를 유지합니다.
아바타 바탕에만 쓰는 보라·청록 옅은 색이 둘 더 있습니다(`--violet-*`, `--teal-*`).

## 4. 글자

- **서체**: Pretendard(앱에 포함). 없으면 Apple SD Gothic Neo → Malgun Gothic.
- **크기**(데스크톱 / 모바일)

| 역할 | 크기 | 굵기 | 행간 |
| --- | --- | --- | --- |
| 화면 제목 | 26 / 24 | 700 | 1.35 |
| 섹션 제목 | 18 / 18 | 700 | 1.4 |
| 패널 제목 | 16 / 16 | 600 | 1.45 |
| 본문 | 15 / 15 | 400 | 1.6 |
| 강조 본문 | 15 / 15 | 600 | 1.55 |
| 라벨·메타 | 13 / 13 | 500 | 1.5 |
| 캡션 | 12 / 12 | 400 | 1.45 |
| 큰 숫자 | 28 / 26 | 700 | 1.2 |

- 18px 이상은 자간 `-0.02em`, 그 아래는 `-0.01em`.
- 영문 대문자 라벨, 넓은 자간 라벨은 쓰지 않습니다. 메타 정보는 가운데 점 대신 간격을 둔 별도 요소로 나열합니다.

## 5. 배치

### 데스크톱 (≥ 960px)

```
┌────────────┬───────────────────────────────────────────────────┐
│ 회사 이름    │                                                   │
│            │  화면 제목 (26/700)                    [옅은] [주]   │
│ 메뉴(흰 바탕) │  설명 한 줄 (15, grey-600)                          │
│ 15px       │                                                   │
│ 선택: 회색   │  ┌ 흰 패널 (radius 16, 그림자 없음) ──────────────┐  │
│  바탕+굵게   │  │ 패널 제목                         보조 동작  │  │
│            │  │ 내용                                          │  │
│ ── 팀       │  └──────────────────────────────────────────────┘  │
│ ── 관리     │                                                   │
│ 내 프로필    │     (앱 배경 grey-50, 본문 최대 1200px, 여백 40px)    │
└────────────┴───────────────────────────────────────────────────┘
```

- 사이드바: 흰 바탕, 오른쪽 1px `--grey-200`. 메뉴 높이 40px, 선택은 `--grey-100` 바탕 + 굵게 + `--grey-900`.
- 상단 바 없이 화면 제목이 머리 역할을 합니다(알림·프로필은 사이드바 아래).
- **관리자 화면**은 패널 안의 표가 중심. 표 위 한 줄에 필터(회색 채운 입력)와 오른쪽 동작.
- 좌측 정렬이 기본. 가운데 정렬은 빈 상태와 로그인 화면에만.

### 모바일 (< 960px)

- 상단 앱 바(흰 바탕, 제목 17/600) + 하단 탭 5개.
- 패널은 화면 폭 가득(좌우 모서리 없음), 패널 사이 8px 회색 띠로 구분 — 앱 같은 느낌.
- 목록은 행(높이 56px, 오른쪽 꺾쇠). 표는 행마다 쌓습니다.
- 모달은 아래에서 올라오는 시트(위 모서리 20px). 주 버튼은 폭 가득, 높이 52px.

## 6. 대표 요소: 하루 막대

이 제품을 기억하게 하는 요소는 **하루 막대**(근무 타임라인)입니다. 장식은 이것 하나에만 씁니다.

```
 06    09 ▼출근 09:12             현재 ▼          18    22
 ├─────┼██████████████████████████░░░░░░░░░░░░░░┼─────┤
       └──── 근무 시간대(09:00–18:00) 옅은 띠 ─────┘
 이번 주 27시간 40분 / 40시간  ███████████████░░░░░░░░
```

- 축은 근무일 전환 시각에서 시작하는 24시간입니다(자정 전환이면 00~24, 야간 근무도 한 줄에 들어갑니다).
- 근무 시간대를 옅은 띠로 깔고, 출근~퇴근(또는 현재)을 브랜드 색 막대로 칠합니다. 지각 구간(근무 시작~출근)은 주의 색.
- 아래에 이번 주(월~일) 누적 근무시간 막대. 축은 60시간이고 40시간·52시간에 표지를 둡니다. 40시간을 넘긴 부분은 주의 색, 52시간을 넘으면 위험 색.
- 막대는 그림이므로 같은 내용을 한 문장(`aria-label`)으로도 줍니다.
- 홈의 오늘 카드, 근태 화면 상단에 크게. 팀 현황의 각 행에는 높이 6px의 작은 막대로 반복합니다.

## 7. 구성 요소

| 요소 | 규칙 |
| --- | --- |
| 버튼 | 높이 40(기본)/32(작게)/52(모바일 주 동작), 모서리 10, 글자 15/600. 주 · 옅은 · 회색 · 위험(빨간 옅은). 아이콘만 있는 버튼은 `aria-label` 필수 |
| 입력 | 높이 44, `--grey-100` 바탕, 테두리 없음, 모서리 10, 글자 16. 포커스 시 `--blue` 2px 안쪽 테두리. 라벨은 위(13/500, grey-700), 오류는 아래 빨간 글자 |
| 배지 | 알약(높이 24, 좌우 8), 옅은 바탕 + 진한 글자, 12/600 |
| 표 | 머리는 `--grey-50` 바탕 13/500 grey-600, 행 높이 52, 행 사이 1px `--grey-100`, 세로선 없음, hover 시 `--grey-50` |
| 패널 | 흰 바탕, 모서리 16, 그림자·테두리 없음, 안쪽 여백 24(데스크톱)/20(모바일) |
| 탭 | 글자 16/600, 선택은 `--grey-900` + 아래 2px 막대, 미선택은 `--grey-500` |
| 숫자 타일 | 바탕 없이 라벨(13, grey-600) + 큰 숫자. 타일 사이는 세로 구분선 또는 여백 |
| 아바타 | 이름 첫 글자, 바탕은 구성원 ID로 정한 6색 옅은 색 중 하나(사람마다 고정) |
| 줄 동작 | 표의 줄마다 반복되는 보조 동작(정정 요청, 수정)은 회색 작은 버튼으로, 데스크톱에서는 줄에 마우스를 올리거나 초점이 들어올 때만 보입니다. 삭제처럼 위험한 동작도 줄 안에서는 회색이고, 빨간색은 확인 단계에서만 씁니다 |
| 같은 줄 패널 | 한 줄에 놓인 패널은 높이를 맞춥니다. 짧은 쪽의 빈 상태는 세로 가운데에 놓습니다 |
| 시각 범위 | "09:02 – 18:10", 퇴근 전이면 "09:02 출근". 빈 값 자리 표시(`-`)를 문장 안에 넣지 않습니다 |
| 줄바꿈 | 한국어는 어절 단위(`word-break: keep-all`)로 줄을 바꿉니다. 단어 중간에서 끊지 않습니다 |
| 내부 ID | 사용자에게 내부 ID(UUID)를 보여 주지 않습니다. 이름이나 제목으로 바꿔 보여 줍니다 |
| 빈 상태 | 회색 아이콘 + 한 줄 설명(15, grey-600) + (있으면) 옅은 버튼 |
| 토스트 | 화면 아래 가운데, 진회색(`--grey-800`) 바탕 흰 글자, 모서리 14 |
| 모달 | 모서리 20, 그림자 하나(`0 8px 32px rgb(0 0 0 / 12%)`), 제목 20/700, 하단 버튼 오른쪽 정렬(모바일은 폭 가득) |

## 8. 움직임

- 사용자의 동작에 답하는 움직임만: 모달·시트 열고 닫기(160ms), 펼침(120ms), 토스트(200ms).
- 페이지 진입 애니메이션, 카드마다 나타나는 효과는 쓰지 않습니다.
- `prefers-reduced-motion`이면 모두 끕니다.
