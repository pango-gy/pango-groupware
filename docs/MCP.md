# Claude 연결 매뉴얼 (원격 MCP)

그룹웨어를 Claude 같은 AI 앱에 연결하면, 대화로 그룹웨어 일을 시킬 수 있습니다.

> "다음 주 월요일부터 수요일까지 연차 기안 올려 줘. 사유는 가족 여행."
> "내 결재함에 대기 중인 거 보여 주고, 출장비 정산은 승인해 줘."
> "전 직원 대상으로 '12월 24일 오후 반차' 공지 올려 줘." (관리자)

AI 앱은 **연결한 사람의 권한으로만** 일합니다. 그 사람이 웹 화면에서 할 수 없는 일은 AI도 할 수 없고, 한 일은 그 사람 이름으로 감사 로그에 남습니다. 결재 알림·공지 알림도 웹에서 한 것과 똑같이 나갑니다.

## 1. 할 수 있는 일

연결할 때 동의 화면에서 아래 권한을 승인합니다.

| 권한 | 도구 | 누가 |
| --- | --- | --- |
| **조회** | 오늘 요약, 오늘·월별 근태, 남은 연차, 휴가 종류·내 휴가 신청, 결재함·결재 문서, 결재 양식·추천 결재선, 구성원 찾기, 공지 목록·보기 | 모두 |
| **변경** | 휴가 신청·취소, 결재 기안·임시저장 상신, 결재 승인·반려·회수, 출근·퇴근, 공지 읽음 확인 | 모두 |
| **관리** | 공지 게시(대상 전원에게 알림) | 관리자·최고 관리자만 |

- 관리자가 아닌 사람이 연결하면 "관리" 권한은 자동으로 빠집니다.
- 휴가 신청은 결재 문서로 올라가며, 결재선을 말하지 않으면 추천 결재선(상위 조직장)을 씁니다.
- 승인·반려·회수·휴가 취소·공지 게시는 되돌리기 어려워, AI 앱이 실행 전에 확인을 묻도록 표시해 둡니다.
- 첨부파일 올리기·내려받기와 관리자 화면의 다른 작업(구성원·근태 수정 등)은 아직 MCP로 하지 않습니다.

## 2. 운영자: 켜기

### 조건

- 그룹웨어가 **공개 인터넷에서 HTTPS로** 열려 있어야 합니다. Claude(claude.ai)는 Anthropic 서버가 `/mcp`, `/oauth/register`, `/oauth/token`, `/.well-known/*`을 부르고, 사용자의 브라우저가 `/oauth/authorize`를 엽니다. VPN이나 IP 허용 목록 뒤에 있으면 연결할 수 없습니다.
- 리버스 프록시가 위 경로를 그대로 서버로 넘겨야 합니다(일반적인 "모든 경로 프록시" 설정이면 됩니다).

### 실행 옵션

```bash
pango-groupware --data-dir /var/lib/pango serve \
  --public-origin https://gw.example.com \
  --trust-proxy \
  --mcp
```

| 옵션 | 환경 변수 | 설명 |
| --- | --- | --- |
| `--mcp` | `PANGO_MCP=true` | 원격 MCP와 OAuth 인가 서버를 켭니다. 끄면 `/mcp`는 503이고 OAuth 경로는 없습니다 |
| `--public-origin` | `PANGO_PUBLIC_ORIGIN` | **필수.** OAuth issuer가 됩니다. 경로 없는 `https://` 주소. MCP 주소는 `{공개 주소}/mcp` |
| `--mcp-allow-loopback` | `PANGO_MCP_ALLOW_LOOPBACK=true` | Claude Code·Claude Desktop(로컬 설정 파일)처럼 로그인 뒤 이 컴퓨터(`http://localhost`)로 돌아오는 클라이언트도 받습니다. 기본은 claude.ai·claude.com 커넥터만 |

따로 둘 비밀 키는 없습니다(토큰은 무작위 값을 해시로만 저장하고, 로그인 세션에 매달립니다). DB 마이그레이션은 시작할 때 자동으로 적용됩니다.

### 켜졌는지 확인

```bash
curl -si -X POST https://gw.example.com/mcp -H 'content-type: application/json' -d '{}' | grep -i www-authenticate
```

`WWW-Authenticate: Bearer resource_metadata="https://gw.example.com/.well-known/oauth-protected-resource", scope="…"`가 보이면 정상입니다. 503이면 `--mcp`가 꺼져 있습니다.

```bash
curl -s https://gw.example.com/.well-known/oauth-authorization-server
```

`issuer`가 공개 주소와 같아야 합니다.

## 3. 구성원: Claude에 연결하기

연결 주소는 회사 그룹웨어 주소 뒤에 `/mcp`를 붙인 값입니다. 예: `https://gw.example.com/mcp`

### Claude (웹·데스크톱·모바일 앱)

1. Claude의 **설정 → 커넥터(Connectors)** 에서 **사용자 지정 커넥터 추가(Add custom connector)** 를 누릅니다. Team·Enterprise 플랜은 조직 관리자가 먼저 추가해 두어야 할 수 있습니다. 메뉴 이름은 Claude 화면 개편에 따라 조금 다를 수 있습니다.
2. 이름(예: `사내 그룹웨어`)과 주소(`https://gw.example.com/mcp`)를 넣고 추가합니다.
3. **연결(Connect)** 을 누르면 그룹웨어의 **동의 화면**이 브라우저에 열립니다.
   - 요청한 앱 이름, 돌아갈 곳(`claude.ai`), 허락할 일 목록을 확인합니다.
   - 그룹웨어 아이디·비밀번호를 넣고(2단계 인증을 켰다면 인증 앱 코드도) **승인**을 누릅니다.
   - 원하지 않으면 **거부**를 누릅니다(로그인 없이 됩니다).
4. Claude로 돌아오면 연결이 끝납니다. 대화에서 그룹웨어 일을 시켜 보세요.

웹 버전에서 한 번 연결하면 같은 Claude 계정의 데스크톱·모바일 앱에서도 함께 쓸 수 있습니다.

### Claude Code

운영자가 `--mcp-allow-loopback`을 켰을 때만 됩니다.

```bash
claude mcp add --transport http groupware https://gw.example.com/mcp
```

그다음 Claude Code에서 `/mcp`를 열어 `groupware`를 인증하면 브라우저에 같은 동의 화면이 열립니다.

### 이렇게 말해 보세요

- "내 남은 연차 알려 줘."
- "12월 26일 하루 연차 신청해 줘. 사유는 개인 사유."
- "결재 대기 중인 문서 목록 보여 줘." → "두 번째 문서 승인해 줘. 의견은 '확인했습니다'."
- "김팡고 님을 결재자로 해서 '노트북 구매 품의' 일반 기안 올려 줘. 금액은 180만 원."
- "출근 찍어 줘. 오늘은 재택이야."
- (관리자) "개발팀 대상으로 '금요일 서버 점검' 필독 공지 올려 줘."

AI가 휴가 종류·결재 양식·구성원 ID를 스스로 찾아 쓰므로, 이름으로 말하면 됩니다. 승인·반려·공지 게시처럼 중요한 일은 AI가 실행 전에 한 번 더 물을 수 있습니다.

## 4. 연결 끊기와 보안

- **승인 한 번 = 로그인 기기 하나.** 연결은 그룹웨어 **내 정보 → 로그인된 기기**에 `AI 연결(MCP) · Claude`로 보입니다. 거기서 **로그아웃**을 누르면 그 연결이 바로 끊깁니다. 관리자는 **관리 → 구성원 → 로그인된 기기**에서 끊을 수 있습니다.
- 비밀번호를 바꾸거나, 관리자가 비밀번호를 초기화하거나, 계정이 비활성화되면 연결도 함께 끊깁니다. 로그인 세션처럼 14일 동안 쓰지 않거나 90일이 지나면 다시 연결해야 합니다.
- 접근 토큰은 10분, 갱신 토큰은 한 번 쓰면 새로 받습니다. 이미 쓴 갱신 토큰이나 코드가 다시 오면(탈취 의심) 그 연결을 끊고 감사 로그(`oauth.token_reuse`)에 남깁니다.
- 동의 화면의 로그인은 웹 로그인과 같은 시도 제한·2단계 인증을 거칩니다. 승인은 감사 로그 `oauth.grant`(앱 이름, 받은 권한)로 남습니다.
- 앱 이름은 앱이 스스로 밝힌 값이라 그대로 믿지 마세요. 동의 화면의 "돌아갈 곳"이 `claude.ai`(또는 `claude.com`)인지 확인합니다. 돌아갈 곳은 서버가 허용한 주소로만 제한됩니다.
- AI 앱에는 도구 결과(문서 제목·본문, 근태 기록 등)가 전달됩니다. 회사의 AI 사용 정책에 맞춰 연결을 허용하세요.

## 5. 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| "로그인 서비스에 등록할 수 없습니다", 연결 버튼이 실패 | 서버가 `--mcp`로 실행 중인지(`/mcp`가 503이면 꺼짐), 공개 인터넷에서 `/.well-known/oauth-authorization-server`가 열리는지 |
| 401만 나오고 로그인 창이 안 뜸 | `WWW-Authenticate`에 `resource_metadata`가 있는지(2절 확인 명령) |
| 동의 화면에서 "이 브라우저에서 시작한 요청이 아닙니다" | 동의 화면을 연 브라우저에서 그대로 승인해야 합니다. 10분이 지났으면 Claude에서 다시 연결 |
| "아이디 또는 비밀번호가 맞지 않아요" | 그룹웨어 계정으로 로그인합니다(Claude 계정 아님) |
| "임시 비밀번호 상태예요" | 그룹웨어 웹에서 비밀번호를 먼저 바꾼 뒤 다시 연결 |
| 조회는 되는데 신청·승인이 안 됨 | 승인할 때 "변경" 권한이 빠졌을 수 있습니다. 연결을 끊고 다시 연결해 변경 권한까지 승인 |
| 공지 게시가 안 됨 | 관리자 계정인지, 승인할 때 "관리" 권한이 있었는지 |
| 휴가 신청이 거부됨(결재선 오류) | 휴가의 마지막 결재자는 조직장이나 관리자여야 합니다. 결재자를 말하지 않으면 추천 결재선을 씁니다 |
| Claude Code에서 "redirect_uri" 오류 | 운영자가 `--mcp-allow-loopback`을 켰는지 |
